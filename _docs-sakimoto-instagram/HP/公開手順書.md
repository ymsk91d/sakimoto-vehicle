# ホームページ公開手順書(株式会社フォー・レント様)

※まだ公開作業は行っていません。公開して良いタイミングになったら、この手順書どおりに進めてください(所要15分ほど・無料)。

## 1. サイトの中身を確認する

`forrent-site` フォルダ内の `index.html` をダブルクリックすると、ブラウザでそのまま見られます。
ページ構成:

| ファイル | ページ |
|---|---|
| index.html | トップ(強み・口コミ・アクセス) |
| service.html | お部屋探しの流れ |
| properties.html | 物件情報(SUUMOへ誘導) |
| company.html | 会社概要・代表あいさつ・地図 |
| contact.html | お問い合わせ(電話・LINE・フォーム) |

## 2. 無料で公開する(Netlify)

1. https://app.netlify.com で無料アカウントを作成(メールアドレスだけでOK)
2. ログイン後「Sites」→ 画面の点線枠に **forrent-site フォルダごとドラッグ&ドロップ**
3. 数十秒で公開完了。仮のURLが発行されます
4. 「Site configuration」→「Change site name」で `for-rent-yokohama` に変更
   → URLが **https://for-rent-yokohama.netlify.app** になります

## 3. メールフォームを有効化する(初回のみ)

1. 公開後、お問い合わせページのフォームから自分でテスト送信を1回する
2. info@forrent1.com に FormSubmit から「Activate(有効化)」メールが届く
3. メール内のボタンをクリック → 以降、フォームの内容が info@forrent1.com に届くようになります

## 4. 独自ドメインにする(任意・追加費用なし)

すでに **forrent1.com** をお持ちなので、このサイトを `www.forrent1.com` で公開できます。

1. Netlifyの「Domain management」→「Add a domain」→ forrent1.com を入力
2. 案内に従って、ドメインを管理している会社(お名前.com等)の設定画面でDNSレコードを追加
   - ここが一番つまずきやすいので、設定画面を開いた状態で私に聞いてもらえれば案内します
3. SSL(httpsの鍵マーク)はNetlifyが自動で無料設定します

※メール(info@forrent1.com)は今までどおり使えます(MXレコードを変更しなければ影響ありません)。

## 5. 更新したいとき

- 文章・物件・口コミの差し替え → 私(Claude)に「ここをこう変えて」と頼む → 修正済みファイルをNetlifyに再度ドラッグ&ドロップするだけ
- おすすめ物件は properties.html 内の「COMING SOON」の3枠を編集して使います
