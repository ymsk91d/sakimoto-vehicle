# サキモトシャリョウ ｜ Instagram自動更新 セットアップ手順書（Metaアプリ＋トークン取得）

この手順書は、サイトのInstagramを「自動更新」にするための**前準備（あなたの作業）**だけをまとめたものです。
ここで取得する **長期アクセストークン** さえ用意できれば、あとのコード側は担当が組み込みます。

- 所要時間の目安：**30〜60分**（はじめてのMetaダッシュボードなら少し余裕を）
- 難所：パート3〜5（Metaの画面操作）。詰まったら、見えている画面をそのまま共有してください。一緒に進めます。
- ⚠️ Metaの管理画面は表記やボタン位置がよく変わります。**ラベルが少し違っても、意味が近いものを選べばOK**です。

---

## 用意するもの
- [ ] スマホのInstagramアプリ（アカウント切替に使用）
- [ ] **Facebookアカウント**（Meta開発者サイトのログインに必要。無ければ無料作成）
- [ ] PC（ダッシュボード操作はPC推奨）
- [ ] このメモを書き込めるもの（最後にトークン等を控えます）

---

## パート0：はじめに用語だけ（読むだけ）
- **ビジネス/クリエイター（プロ）アカウント**：お店用のInstagram。自動取得APIにはこれが必須。
- **Metaアプリ**：Instagramからデータを取得する「許可証」のようなもの。あなたのFacebookアカウントで作ります。
- **アクセストークン**：APIを使うための鍵。**長期トークン＝約60日有効**（自動更新は後でコード側が面倒を見ます）。
- ✅ **自分のお店の投稿を表示するだけ**なので、面倒な「アプリ審査（App Review）」は**不要**です（開発モードのまま運用OK）。

---

## パート1：Instagramを「プロアカウント」に切り替える
※すでにビジネス/クリエイターの方は **パート2へ**。

1. [ ] Instagramアプリで自分のプロフィールを開く
2. [ ] 右上の **≡（三本線）→「設定とプライバシー」**
3. [ ] **「アカウントの種類とツール」** を開く
4. [ ] **「プロアカウントに切り替える」** をタップ
   - ここが「**個人用アカウントに切り替える**」になっていれば → **すでにプロです**。パート2へ。
5. [ ] **ビジネス**（おすすめ）または **クリエイター** を選ぶ
6. [ ] カテゴリ（例：「自動車サービス」「自動車修理店」など）を選んで完了

> メモ：切替は無料・フォロワーへの通知なし・いつでも個人に戻せます。

---

## パート2：Meta開発者に登録する（初回のみ）
1. [ ] PCで **https://developers.facebook.com** を開く
2. [ ] 右上 **「ログイン」** → お店のFacebookアカウントでログイン
3. [ ] 初回は **「開発者登録」** を求められる → 電話番号/メール認証、規約に同意
4. [ ] 上部メニューに **「マイアプリ（My Apps）」** が出れば登録完了

---

## パート3：Metaアプリを作成する
1. [ ] **「マイアプリ」→「アプリを作成（Create App）」**
2. [ ] 「ユースケースを選択」画面：
   - **Instagram** に関する項目があれば選択
   - 見当たらない場合は **「その他（Other）」→「次へ」→「ビジネス（Business）」** を選択
3. [ ] アプリ名（例：`sakimoto-instagram-feed`）、連絡先メールを入力
4. [ ] （ビジネスポートフォリオの選択を求められたら、無ければ「後で」でも可）
5. [ ] **「アプリを作成」** をクリック（パスワード再入力を求められることあり）

---

## パート4：Instagram連携を追加する
1. [ ] 左メニュー（または「製品を追加」）から **「Instagram」** を探して **「設定（Set up）」**
2. [ ] **「Instagram API setup with Instagram login」**（Instagramログインでのセットアップ）を選ぶ
   - ※「Facebookログイン経由（Graph API）」もありますが、**Instagramログインの方が簡単**なのでこちらを推奨。
3. [ ] 画面に表示される **Instagram app ID / Instagram app secret** をあとで使うので、このページは開いたままに。

---

## パート5：アカウントを接続してトークンを発行する
1. [ ] 同じInstagram設定ページ内の **「アクセストークンを生成（Generate access tokens）」** あたりを探す
2. [ ] **「アカウントを追加（Add account）」** → ポップアップで**お店のInstagram（プロ）アカウントでログイン**
3. [ ] 権限（プロフィール・メディアの閲覧）を **許可（Allow）**
4. [ ] 戻ると **アクセストークン** が表示される → これをコピー
   - ここで「**60日間有効**」など長期と表示されていれば、それが長期トークンです（パート6へ）。
   - 「短期（1時間）」のみの場合は、次の「長期トークンへの変換」を行う。

### （必要な場合のみ）短期 → 長期トークンへの変換
ブラウザのアドレスバーに、下記の `{ }` を自分の値に置き換えて貼り付け、Enter：

```
https://graph.instagram.com/access_token?grant_type=ig_exchange_token&client_secret={Instagram app secret}&access_token={短期トークン}
```

- 返ってきた JSON の `access_token` が **長期トークン（約60日）** です。これを控えます。

あとでコード側に渡す/登録するために、以下を安全な場所にメモしてください
（**チャットやメールに平文で貼らない**でください。登録は管理画面のSecret欄に直接行います）。

- [ ] **長期アクセストークン**：`____________________`
- [ ] **InstagramユーザーID**：`____________________`
  - 取得方法：アドレスバーに下記を貼ってEnter → 出てきた `id` がそれ
    ```
    https://graph.instagram.com/me?fields=id,username&access_token={長期トークン}
    ```

- [ ] **Instagram app ID**：`____________________`
- [ ] **Instagram app secret**：`____________________`

> この4つが揃えば前準備は完了です。担当に「準備できました」と伝えてください
> （トークン等は、こちらが用意するGitHub/サーバーのSecret欄にあなたが直接貼る形にします）。

## 動作確認（任意・やると安心）
アドレスバーに下記を貼ってEnter。最近の投稿一覧（JSON）が返ってくれば成功です：

```
https://graph.instagram.com/me/media?fields=id,caption,media_type,media_url,permalink,thumbnail_url,timestamp&access_token={長期トークン}
```

## 補足・注意
- **App Review（アプリ審査）は不要**：自分のアカウントの投稿表示は、アプリを**開発モードのまま**で運用できます。「公開（Live）」に切り替える必要はありません。
- **トークンの60日期限**：心配いりません。サイト側の自動処理で、期限前に自動更新（`refresh_access_token`）するよう組み込みます。
- **将来のサーバー移転（ConoHa WING）後も継続OK**：取得処理はPHPで作るので、移転後はConoHaのcronに実行を移すだけ。トークン/アプリはそのまま使えます。
- **Metaの画面が手順書と違うとき**：ラベルが変わっているだけのことが多いです。スクショを共有いただければその場で案内します。
